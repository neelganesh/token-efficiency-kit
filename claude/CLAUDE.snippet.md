## Model routing (Claude Code)
- Main session on Sonnet. Haiku only for read-only or mechanical work (search, sweeps, formatting). Judgment and code-writing stay on Sonnet.
- Opus only through the `opus-reviewer` agent, only when a mistake is costly. Give it a brief, not history.
- Delegate to a subagent only when the side task would flood context with output you will not reuse. Small tasks stay inline.
